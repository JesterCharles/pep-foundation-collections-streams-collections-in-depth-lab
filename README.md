# Collections in Depth — Code lab

Finish a warehouse's order-routing registry: store orders by key, queue them at packing stations, dispatch and undo, and print two reports. One collection idea per task.

- **Edit:** `RoutingRegistry.java` (and `OrderKey.java`) in `src/main/java/exercise/`. Each task is marked `TODO`.
- **Run the tests:** **Run Tests** in Exa Studio, or `mvn test` with JDK 17 and Maven. All 6 visible tests fail at first; every message starts with `Task N:`.
- **Done** when every visible test passes. **Submit** also runs held-out tests you can't see.

Full task steps and hints: [`.evolv/instructions.md`](.evolv/instructions.md)
